# Talkie Homebrew Tap

Install Talkie for Mac:

```sh
brew install --cask arach/talkie/talkie
```

Talkie is a local-first voice dictation and workflow app for Apple silicon Macs
that run macOS 14 or later.

- [Talkie for Mac](https://usetalkie.com/mac/)
- [Releases](https://github.com/arach/usetalkie.com/releases)

To remove Talkie, run `brew uninstall --cask talkie`.
